# 二维小球碰撞模拟

用纯标准库实现一个二维刚体小球碰撞模拟：N 个小球在矩形边界里运动，球和球发生完全弹性碰撞，球和墙发生弹性反射。

## 物理模型

- 每个球有位置 (x, y)、速度 (vx, vy)、半径 radius、质量 mass。质量只影响球和球碰撞后的速度分配，不影响墙反射。
- 球和墙：碰到边界（x - radius < 0 或 x + radius > width，y 同理），位置夹回边界内，对应速度分量取反。
- 球和球：完全弹性碰撞，动量和动能同时守恒。等质量时两球沿法向交换速度分量；质量不等时按弹性冲量公式分配：
  - 法向 n 从球 i 指向球 j，接近速度 vrel = (vi - vj)·n > 0 时施加冲量
  - jimp = -2·vrel / (1/mi + 1/mj)
  - vi += (jimp/mi)·n，vj -= (jimp/mj)·n
- 用固定时间步长 dt 积分，位置更新是 `x += vx·dt`。碰撞是离散检测的，检测到重叠要先把两球沿法向分开（各移重叠量的一半），再施加速度冲量，否则会穿模。

真正的坑都在细节里：碰撞响应写错公式能量就暴涨或衰减；重叠了不修复就穿模；同一个球一步里同时撞墙又撞球、或者三球同时撞，处理顺序不对会漏碰撞或引入额外能量。

## 场景文件

判分脚本会生成 JSON 场景文件，格式：

```json
{
  "width": 10.0,
  "height": 10.0,
  "duration": 10.0,
  "dt": 0.001,
  "balls": [
    {"x": 2.0, "y": 3.0, "vx": 1.5, "vy": -0.5, "radius": 0.4, "mass": 1.0}
  ]
}
```

`dt` 是固定步长，模拟从 t=0 到 t=duration。

## 你要交付什么

写一个 `sim.py`，命令行入口：

```bash
python3 sim.py <场景.json>
```

读进场景，用固定步长 dt 模拟到 duration，每个步长输出一行到标准输出：

```
t x0 y0 x1 y1 ... x_{N-1} y_{N-1} energy
```

- 位置按场景 balls 数组的顺序输出。
- `energy` 是该时刻总动能，`sum(0.5·mass·(vx²+vy²))`。
- 全是空格分隔的十进制数，不要表头、不要注释行。

全程本地，只许用标准库。

## 判分标准（`grade.py`）

```bash
python3 grade.py
```

`grade.py` 生成 5 个固定种子的场景（2 到 4 个球），跑 `python3 sim.py <场景.json>`，检查：

- **不穿透**：每一帧每个球都在边界内（x - radius >= 0、x + radius <= width 等），任意两球距离不小于半径和。
- **能量守恒**：每一帧总动能相对初始总动能的漂移小于 1%。完全弹性碰撞下动能严格守恒，能量暴涨或衰减都说明碰撞响应写错了。
- **球真的在动**：末帧相对初帧的总位移大于阈值，防止输出一条冻结的假轨迹。
- **确定性**：相同场景跑两遍，输出逐字节一致。

5 个场景全过输出 `PASS`，退出码 0；任何一个不过输出 `FAIL`，退出码非 0。

## 约束

- 全程本地离线，只许用标准库。
- 不要用现成的物理引擎。碰撞检测、冲量响应、穿透修复全自己写。
- 初始动能非零，球一定在动；能量和穿透两项是最硬的指标，写错任何一处都过不了。
